# Changelog

## 0.3.0 - 2026-06-27

- Added a corpus-neutral Knowledge Platform foundation with strict metadata,
  ontology, collection, indexing, graph, vector-profile and pipeline contracts.
- Added cross-artifact validation, repository-bound source metadata and
  adversarial tests while keeping every ingestion and retrieval runtime off.
- Preserved source ownership outside the framework and avoided empty corpus
  scaffolding or unsupported file-format claims.

## 0.2.0 - 2026-06-27

- Added a schema-validated, autonomous Advanced RAG capability specification
  with nine component contracts, registry, manifest, documentation and tests.
- Added contract compatibility policy, maturity metadata, dependency inventory
  and negative tests for missing dependencies, invalid types and incompatible
  versions.
- Kept every external RAG adapter disabled and the runtime non-installable.
- Added schema-validated framework, module, service, model, port, network and
  volume bootstrap catalogs with idempotent initialization checks.
- Added opt-in Ollama and LiteLLM Compose contracts with immutable image
  digests, loopback-only ports, health checks and explicit installers.
- Added pinned Open WebUI and OpenHands contracts with private defaults,
  schema-validated AI routing and an explicit Docker-socket risk gate.
- Added strict PostgreSQL, Redis, Neo4j and Qdrant contracts with immutable
  images, local-only ports, authentication, health checks and restore gates.
- Added n8n, SearXNG, Prometheus, Grafana and Loki contracts with immutable
  images, private defaults, typed dependencies and honest observability gaps.

## 0.1.0 - 2026-06-27

- Added executable JSON Schema validation for project manifests and their
  registry.
- Added a deterministic verification entry point.
- Locked Python 3.12 dependencies with `uv.lock` and made bootstrap consume the
  lock without source-tree build artifacts.
- Removed generated files, empty placeholders and inactive platform skeletons.
- Reconciled the historical v2 specification archive with the autonomous
  framework boundary; project-specific and inactive runtime artifacts remain
  excluded.
